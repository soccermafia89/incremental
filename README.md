# Incremental

Scaffold for a new game, laid out like Galactica: Vite + React + TypeScript,
a pure core, one `GameService`, save/load, the same screen shell, and an
HTTP/MCP server.

The game rules are not written yet. `Game` is empty. There is no turn loop.

**How to run it:** [HOW-TO-PLAY.md](HOW-TO-PLAY.md)

Agents start at [AGENTS.md](AGENTS.md).
